# Job Search Agent Starter

Локальный помощник для поиска работы на HH: подбор вакансий по вашему профилю,
выбор резюме, подготовка сопроводительных писем и ежедневный отчёт.
Настраивается через Codex. Поддерживает одно или несколько резюме.

## Что умеет

- Искать вакансии через собственный доступ к HH API, сохранять их в SQLite и убирать дубли.
- Сопоставлять вакансии с вашими критериями и подтверждёнными карьерными фактами;
  проверять явно обязательные квалификации до платной подготовки.
- Готовить локальные черновики; по отдельному разрешению — письма через OpenAI Responses API
  с общим бюджетом и независимой проверкой полного текста по источникам.
- Формировать HTML/Markdown-отчёты и почтовое превью.
- По отдельной настройке — подготавливать и отправлять отклики через собственный профиль Chrome,
  проверять историю и подтверждение отправки, доставлять отчёт по SMTP или своему Google Apps Script.
- Сохранять вопросы работодателей в локальную очередь: профессиональные ответы проходят
  отдельную проверку; личные решения требуют подтверждения владельца.
- Создавать конфигурацию ежедневного запуска macOS; расписание устанавливает владелец.
  Блокировка параллельного цикла и сохранённые этапы защищают от повторной работы.

**По умолчанию внешние подключения, платные вызовы, отправка откликов и почта выключены.
Расписание не установлено.** Личных резюме, базы, ключей и браузерных сессий в репозитории нет.

## Требования

Полная цепочка рассчитана на **Mac**: Python 3.11+, Node.js 20+, npm и Google Chrome.
Для первоначальной настройки нужен Codex. Python использует стандартную библиотеку;
Playwright устанавливается отдельно по `package-lock.json`.
Проверенная среда: Python 3.14, Node.js 24.14, Playwright 1.64.1.

HH, OpenAI и доставка отчётов подключаются к **вашим** аккаунтам с вашим участием.
Наличие подписки на ChatGPT/Codex не заменяет собственный доступ и бюджет OpenAI API.

## Быстрый старт через Codex

1. Скачайте проект через **Code → Download ZIP** и распакуйте на Mac либо клонируйте репозиторий.
2. Откройте в Codex папку, в которой находятся `START_HERE.md` и `portable.py`.
   У ZIP из GitHub она может называться `job-search-agent-starter-main`.
3. Откройте [CODEX_SETUP_PROMPT.md](CODEX_SETUP_PROMPT.md), скопируйте промт и отправьте его в Codex.
4. Codex поможет проверить ПО и последовательно настроить ваши резюме, профиль,
   критерии и подключения. Логин, разрешения и секреты требуют ваших личных действий;
   секреты вводите в своём терминале, не в чате.
5. Сначала проверьте поиск, качество подбора и писем. Автоматическую отправку включайте
   после проверки, успешной подготовки формы без отправки и отдельного разрешения.

Изменения от 6 ноября 2026 года: [CHANGELOG.md](CHANGELOG.md).

Подробные шаги и команды: **[START_HERE.md](START_HERE.md)**.

## Ограничения и приватность

Matching — эвристика по критериям и подтверждённым фактам, он не доказывает полного соответствия
вакансии. Неизвестный опыт нельзя заменять выдуманным. Тесты работодателей, согласия,
неизвестные обязательные вопросы и защиты платформы требуют ручной обработки.
Агент не обходит CAPTCHA и не повторяет автоматически неопределённую отправку.

Работа зависит от доступа к сервисам и текущей разметки HH. Платная генерация, реальная отправка,
входящие письма и расписание требуют проверки на вашей установке.
Полная работа на Windows/Linux не подтверждена. Подробности: [VALIDATION.md](VALIDATION.md).

После настройки не отправляйте в публичный Git ваши локальные изменения профиля и конфигураций:
пустые шаблоны уже отслеживаются Git, и `.gitignore` не скрывает изменения отслеживаемых файлов.
Не публикуйте `cv/`, `var/`, секреты, снимки HH-резюме, отчёты и историю откликов.

## Офлайн-проверки

После установки ПО и зависимостей по `START_HERE.md`:

```bash
python -m unittest discover -s tests -v
node --test tests/*.mjs
python portable.py demo
```

Проверки используют вымышленные данные и двойники сервисов. Реальные HH/OpenAI/почтовые
вызовы не нужны. Аудит публикации: [PUBLICATION_AUDIT.md](PUBLICATION_AUDIT.md).
