# Изменения

## 2026-11-06

Синхронизация универсальных исправлений после первой публикации от 2026-11-04.

- Matching различает обязательные условия, пожелания и уточнения в скобках. Явный стаж
  в конкретной области, образование и названные инструменты требуют подтверждения до
  платной подготовки. Названия направлений, число CV и критерии остаются настройками владельца.
- NET/GROSS не пересчитываются автоматически. Бонусная часть не подтверждает достаточный фикс.
- Генерация полного письма и независимая проверка всех сегментов по точным источникам;
  связка письма, вакансии, CV, фактов и политики проверки. Повторное использование актуального
  результата или проверка сохранённого текста; незавершённый запрос не повторяется автоматически.
- Общие дневные/месячные бюджеты для писем, проверок и профессиональных ответов;
  новые ограничения применяются к работающей пачке, неясные расходы сохраняются в резерве.
- Очередь вопросов с локальным подтверждением, ограничением длины поля и вариантов,
  привязкой к вакансии/форме/фактам. Продолжение подтверждённых ответов без нового поиска.
- Полное чтение вкладок истории HH с последовательной пагинацией до платной подготовки;
  пустой набор ID обрабатывается как пустой. Неопределённые отправки не освобождаются.
- Повторная пауза непосредственно перед нажатием. Восстановление прерывания до нажатия
  требует доказательства из журнала и свежей полной истории.
- Блокировка параллельного дневного цикла, сохранение завершения дня, продолжение этапов;
  почта с прежним статусом попытки, Markdown-проверка качества и фактическая воронка.
- Python-канал Apps Script использует точного получателя владельца и проверяет его в квитанции.
  Зависимости и сервисы сохранены; README и технические инструкции обновлены.

### Намеренные отличия

Один или несколько произвольно названных CV вместо фиксированных профилей. Зарплата, английский,
география, бюджеты, время и лимит откликов берутся из конфигурации владельца. История, Keychain,
браузер и расписание изолированы. Все внешние функции выключены. Разовые разрешения прежней
установки, обход паузы для специального запуска, персональные исключения работодателей,
фиксированные дневные цели и частные карьерные/проектные сведения не перенесены.

HH API не получил новых эндпоинтов или способов авторизации; собственная настройка сохранена.
Расписание генерируется для локальных часов Mac; установка требует действий владельца.
Полная работа с реальными аккаунтами в этом обновлении не проверялась.
